# engineering

Engineering turns abstract intent into a system with explicit boundaries, contracts, and verification.

Primary public focus:

- Swift and native Apple-platform development;
- Ruby for compact service and domain implementations;
- C as a thinking tool for structures, types, and algorithms;
- browser and server systems where the architecture requires them.

The module consumes [`knowledge`](../knowledge/README.md) and produces the systems described in [`systems`](../systems/README.md).
