# knowledge

Knowledge is curated context that remains useful across projects and tools.

It contains stable models, vocabulary, decisions, and references. Raw conversation history, temporary notes, and private memory do not belong here.

## Domains

- software architecture and system contracts;
- mobile and distributed systems;
- human-to-human and human-to-system relationships expressed as explicit actions;
- provider-independent product and commerce infrastructure;
- language as both interface and meaning.

Knowledge is consumed by [`engineering`](../engineering/README.md) and may be expressed through [`writing`](../writing/README.md).
