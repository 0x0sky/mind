# writing

Writing is a public part of the identity rather than an annotation around engineering.

The practice combines contemporary Ukrainian poetry, technical vocabulary, multilingual rhythm, and software metaphors without treating language as decoration.

Writing may consume concepts from [`knowledge`](../knowledge/README.md), but its canonical works belong in their own publishing surfaces rather than being duplicated into this repository.

The durable publishing model is described in [`publishing`](publishing/README.md). It defines the scale of the public system without binding `mind` to specific platforms, channels, accounts, or transient distribution strategy.
